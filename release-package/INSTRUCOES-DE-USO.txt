🎯 O QUE É ESTE PROGRAMA?
================================================================================

O Organizador de Capturas monitora automaticamente uma pasta de screenshots
e organiza tudo por data de forma inteligente:

  ANTES:                           DEPOIS:
  📁 Screenshots/                  📁 Screenshots/
  ├── captura (1).png              ├── 2026/
  ├── captura (2).png              │   ├── 02-Fevereiro/
  ├── captura (3).png              │   │   ├── 25/
  └── captura (9999).png           │   │   │   ├── captura1.png
                                   │   │   │   └── captura2.png

Nunca mais perca tempo procurando aquela captura! 🎉


🚀 COMO USAR (SUPER FÁCIL)
================================================================================

1️⃣ PRIMEIRA EXECUÇÃO:
─────────────────────

   a) Duplo clique em: OrganizadorCapturas.exe
   
   b) Selecione a pasta que deseja monitorar
      (Ex: C:\Users\Você\Box\Screenshots)
   
   c) Pronto! O ícone 📁 aparecerá na bandeja do sistema
      (próximo ao relógio)


2️⃣ USANDO O PROGRAMA:
──────────────────────

   • Tire suas capturas normalmente (PrintScreen, Greenshot, etc.)
   
   • Salve na pasta que você configurou
   
   • O organizador move AUTOMATICAMENTE para:
     Ano/Mês-Nome/Dia/
   
   • Duplicatas são detectadas e removidas automaticamente!


3️⃣ MENU DO ÍCONE (Botão direito no 📁):
────────────────────────────────────────

   📊 Ver Logs e Status    - Abre janela com logs em tempo real
   ⏸️ Pausar               - Pausa o monitoramento
   ▶️ Retomar              - Retoma o monitoramento
   ⚙️ Configurar Pasta     - Muda a pasta monitorada
   🚀 Iniciar com Windows  - Auto-start (liga/desliga)
   🚪 Sair                 - Fecha o programa


✨ FUNCIONALIDADES
================================================================================

✅ Monitoramento Automático
   • Detecta novos arquivos em tempo real
   • Funciona em segundo plano
   • Usa pouquíssimos recursos (<30 MB RAM)

✅ Organização Inteligente
   • Estrutura: Ano/Mês-Nome/Dia/
   • Extrai data do nome do arquivo
   • Usa data de modificação como fallback
   • Meses em português (Janeiro, Fevereiro, etc.)

✅ Anti-Duplicatas
   • Detecta capturas idênticas (hash MD5)
   • Remove duplicatas automaticamente
   • Economiza espaço em disco

✅ Interface Amigável
   • Ícone 📁 na bandeja com cores dinâmicas:
     🟢 Verde = Ativo
     🟡 Amarelo = Pausado
     🔴 Vermelho = Erro
   • Janela de logs em tempo real
   • Configuração fácil via GUI

✅ Auto-Start no Windows
   • Inicia automaticamente ao ligar o PC
   • Configuração com 1 clique


🔧 CONFIGURAÇÃO AVANÇADA
================================================================================

RECONFIGURAR PASTA:
───────────────────
1. Botão direito no ícone 📁
2. "⚙️ Configurar Pasta"
3. Selecione nova pasta
4. Reinicie o programa


HABILITAR AUTO-START:
──────────────────────
1. Execute o programa COMO ADMINISTRADOR (botão direito > Executar como Admin)
2. Clique com botão direito no ícone 📁
3. Clique em "🚀 Iniciar com Windows"

Se der erro de permissão:
• Escolha "Sim" para usar método alternativo (Pasta Startup)


VER LOGS COMPLETOS:
───────────────────
1. Botão direito no ícone 📁
2. "📊 Ver Logs e Status"
3. Clique em "Abrir Pasta" para ver organizador.log


⚠️ ANTIVÍRUS BLOQUEOU?
================================================================================

Alguns antivírus podem bloquear o programa (FALSO POSITIVO).

ISSO É NORMAL! O programa é 100% seguro.

SOLUÇÃO RÁPIDA:
───────────────

Windows Defender:
1. Configurações do Windows
2. Privacidade e Segurança → Segurança do Windows
3. Proteção contra vírus e ameaças
4. Gerenciar configurações → Exclusões
5. Adicionar exclusão → Arquivo
6. Selecione OrganizadorCapturas.exe

Kaspersky:
1. Configurações → Proteção → Proteção contra Ameaças
2. Exclusões → Gerenciar exclusões
3. Adicionar → Arquivo
4. Selecione OrganizadorCapturas.exe

Outros antivírus:
• Procure por "Exclusões" ou "Exceções"
• Adicione OrganizadorCapturas.exe

POR QUE É FALSO POSITIVO?
──────────────────────────
• Código 100% aberto: github.com/fabri2896/organizador-capturas
• Não se conecta à internet
• Não pede senhas ou dados sensíveis
• PyInstaller (ferramenta usada) é detectada por engano


🛠️ SOLUÇÃO DE PROBLEMAS
================================================================================

PROBLEMA: Ícone não aparece na bandeja
SOLUÇÃO: 
  • Aguarde 5-10 segundos
  • Procure na área de "ícones ocultos" (seta para cima)
  • Verifique se o antivírus bloqueou


PROBLEMA: Não está organizando arquivos
SOLUÇÃO:
  • Botão direito no ícone → "Ver Logs e Status"
  • Verifique se está PAUSADO (ícone amarelo)
  • Clique em "▶️ Retomar"
  • Verifique se a pasta está correta


PROBLEMA: Auto-start não funciona
SOLUÇÃO:
  • Execute como Administrador uma vez
  • Configure auto-start novamente
  • Ou use método alternativo (Pasta Startup)


PROBLEMA: Erro ao iniciar
SOLUÇÃO:
  • Verifique se a pasta configurada ainda existe
  • Delete o arquivo config.json (na mesma pasta do EXE)
  • Execute novamente e configure nova pasta


📋 REQUISITOS DO SISTEMA
================================================================================

Sistema Operacional:
  • Windows 10 ou superior (64-bit)
  • Windows 11 (recomendado)

Espaço em Disco:
  • ~100 MB para o programa
  • Espaço adicional para capturas organizadas

Memória RAM:
  • Mínimo: 2 GB
  • Usa apenas ~30 MB quando rodando

Outros:
  • Pasta de capturas deve estar acessível
  • Permissões de leitura/escrita na pasta


📁 ARQUIVOS GERADOS
================================================================================

config.json - Configuração da pasta monitorada
  • Criado automaticamente na primeira execução
  • Pode ser editado manualmente
  • Localização: mesma pasta do EXE

organizador.log - Log de todas as operações
  • Registra tudo que o programa faz
  • Útil para diagnóstico de problemas
  • Localização: mesma pasta do EXE


🔄 ATUALIZAÇÃO
================================================================================

Para atualizar para uma nova versão:

1. Feche o organizador (Botão direito → Sair)
2. Substitua o EXE antigo pelo novo
3. Execute normalmente

Suas configurações (config.json) são mantidas!
