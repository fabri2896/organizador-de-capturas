🎯 SOBRE O EXECUTÁVEL
================================================================================

O arquivo "OrganizadorCapturas.exe" é uma versão PORTÁTIL do organizador.

VANTAGENS:
  ✅ NÃO precisa instalar Python
  ✅ NÃO precisa instalar dependências  
  ✅ Funciona com DUPLO CLIQUE
  ✅ Pode copiar para qualquer lugar
  ✅ Mesmas funcionalidades da versão Python

REQUISITOS:
  • Windows 10 ou superior
  • Aproximadamente 30 MB de espaço em disco


🚀 COMO USAR
================================================================================

PRIMEIRA EXECUÇÃO:
  1. Duplo clique em "OrganizadorCapturas.exe"
  2. Aguarde 2-3 segundos (pode demorar um pouco na primeira vez)
  3. Selecione a pasta que deseja monitorar
  4. Pronto! O ícone 📁 aparecerá na bandeja do sistema

EXECUÇÕES SEGUINTES:
  • Duplo clique e já inicia monitorando
  • Configuração é salva em "config.json"


🎨 ÍCONE NA BANDEJA
================================================================================

O ícone muda de cor conforme o status:

  🟢 VERDE   = Ativo e monitorando
  🟡 AMARELO = Pausado temporariamente
  🔴 VERMELHO = Erro ou problema

MENU (clique com botão direito):
  📊 Ver Logs e Status        - Abre janela com logs em tempo real
  ⏸️ Pausar                   - Pausa monitoramento
  ▶️ Retomar                  - Retoma monitoramento
  ⚙️ Configurar Pasta         - Muda a pasta monitorada
  🚀 Iniciar com Windows      - Habilita/desabilita auto-start
  🚪 Sair                     - Encerra o organizador


🚀 AUTO-START (INICIAR COM WINDOWS)
================================================================================

Para o organizador iniciar automaticamente quando você ligar o PC:

  1. Execute o "OrganizadorCapturas.exe"
  2. Clique com BOTÃO DIREITO no ícone da bandeja
  3. Clique em "🚀 Iniciar com Windows"
  4. Pronto! ✅

Na próxima vez que você ligar o computador, o organizador já estará rodando!

Para DESABILITAR:
  • Clique novamente em "🚀 Iniciar com Windows" (desmarcar)


📁 COMO FUNCIONA A ORGANIZAÇÃO
================================================================================

O organizador monitora a pasta configurada e:

  1. Detecta novos arquivos de imagem (.png, .jpg, .jpeg, .gif, .bmp, .webp)
  2. Extrai a data do nome do arquivo (formato YYYY-MM-DD)
  3. Se não encontrar data no nome, usa a data de modificação
  4. Organiza em: Ano/Mês-Nome/Dia/
  
EXEMPLO:
  Arquivo: "2026-02-25 10_30_45-captura.png"
  
  Será movido para:
    Screenshots/
    └── 2026/
        └── 02-Fevereiro/
            └── 25/
                └── 2026-02-25 10_30_45-captura.png


🗑️ DETECÇÃO DE DUPLICATAS
================================================================================

O organizador usa HASH MD5 para detectar imagens idênticas:

  • Se você tentar salvar a mesma captura duas vezes
  • A duplicata será AUTOMATICAMENTE REMOVIDA
  • Economiza espaço em disco
  • Aparece nos logs: "🗑️ Duplicata detectada"


📊 LOGS E STATUS
================================================================================

Para ver o que está acontecendo:

  1. Clique com botão direito no ícone
  2. Selecione "📊 Ver Logs e Status"
  
A janela mostra:
  • Status atual (Ativo/Pausado)
  • Pasta sendo monitorada
  • Total de arquivos organizados
  • Logs em tempo real de todas as operações

BOTÕES:
  [Limpar]      - Limpa a tela de logs
  [Atualizar]   - Atualiza informações de status
  [Abrir Pasta] - Abre a pasta monitorada no Explorer
  [Fechar]      - Fecha a janela (organizador continua rodando)


⚠️ ANTIVÍRUS E FIREWALL
================================================================================

IMPORTANTE: Alguns antivírus podem bloquear o EXE (FALSO POSITIVO)

Se isso acontecer:
  1. Adicione "OrganizadorCapturas.exe" nas EXCEÇÕES do antivírus
  2. Ou compile você mesmo usando "compilar_para_exe.bat"

🔧 SOLUÇÃO DE PROBLEMAS
================================================================================

PROBLEMA: O ícone não aparece na bandeja
SOLUÇÃO: 
  • Aguarde 5-10 segundos
  • Verifique a área de "ícones ocultos" (seta para cima)
  • Execute como Administrador

PROBLEMA: Não está organizando os arquivos
SOLUÇÃO:
  • Clique com botão direito > "Ver Logs e Status"
  • Verifique se está PAUSADO (amarelo)
  • Clique em "▶️ Retomar"

PROBLEMA: Erro ao iniciar
SOLUÇÃO:
  • Verifique se a pasta configurada ainda existe
  • Delete o arquivo "config.json" e execute novamente
  • Configure uma nova pasta

PROBLEMA: Auto-start não funciona
SOLUÇÃO:
  • Execute o EXE como Administrador uma vez
  • Configure o auto-start novamente
  • Reinicie o computador para testar


📦 ARQUIVOS GERADOS
================================================================================

Ao usar o EXE, os seguintes arquivos são criados:

  config.json       - Configuração da pasta monitorada
  organizador.log   - Log de todas as operações
  
Esses arquivos ficam na MESMA PASTA que o EXE.

IMPORTANTE: Não delete esses arquivos se quiser manter a configuração!


💾 ATUALIZAÇÃO
================================================================================

Para atualizar para uma nova versão:

  1. Feche o organizador (Botão direito > Sair)
  2. Substitua o "OrganizadorCapturas.exe" pela nova versão
  3. Execute novamente
  
Suas configurações (config.json) são mantidas!
