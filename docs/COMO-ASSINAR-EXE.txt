ASSINATURA DIGITAL (OPCIONAL, PARA QUEM FOR DISTRIBUIR)
================================================================

Assinar remove o aviso do SmartScreen e evita bloqueios corporativos. Não é
obrigatório: sem assinatura o programa funciona normalmente, só mostra o
aviso "O Windows protegeu o seu PC" na primeira execução.

TIPOS DE CERTIFICADO
--------------------
Certificado OV (organização validada)
    ~US$ 100-300/ano. Ainda passa por reputação: o SmartScreen pode avisar
    até o arquivo acumular downloads.

Certificado EV (validação estendida)
    ~US$ 300-600/ano, com token físico ou HSM. Dá confiança imediata no
    SmartScreen, sem período de carência. É o que empresas usam.

Alternativa gratuita
    Não existe certificado público gratuito aceito pelo Windows. O
    SignPath.io oferece assinatura gratuita para projetos open source
    aprovados — vale tentar se o projeto crescer.

ASSINAR O INSTALADOR (Signtool)
-------------------------------
O signtool vem no Windows SDK. Exemplo:

    signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
        /f meu-certificado.pfx /p SENHA ^
        "Output\OrganizadorCapturas-2.0.2-Setup.exe"

Parâmetros:
    /fd SHA256              algoritmo do arquivo
    /tr ... /td SHA256      timestamp (mantém a assinatura válida após o
                            certificado expirar)
    /f /p                   arquivo .pfx e senha (ou use /a com o
                            certificado já instalado no repositório)

Com token EV, troque /f /p por /sha1 <impressão digital> ou use o
fornecedor (ex.: SafeNet) para o certificado ficar disponível.

VERIFICAR A ASSINATURA
----------------------
    signtool verify /pa /v "Output\OrganizadorCapturas-2.0.2-Setup.exe"

Ou, no Explorador: botão direito > Propriedades > Assinaturas Digitais.

ASSINAR TAMBÉM O EXE
--------------------
O instalador assina o Setup, mas o EXE interno pode ficar sem assinatura.
Para assinar os dois, rode o signtool no EXE antes de compilar o instalador:

    signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
        /f meu-certificado.pfx /p SENHA ^
        "dist\OrganizadorCapturas\OrganizadorCapturas.exe"

Ou adicione SignTool=... na seção [Setup] do scripts/installer.iss.

CUSTO x BENEFÍCIO
-----------------
- Projeto pessoal / poucos usuários: pode ficar sem assinatura
- Distribuição ampla: certificado OV resolve a maior parte dos casos
- Uso corporativo: EV, porque políticas de empresa bloqueiam não assinados
