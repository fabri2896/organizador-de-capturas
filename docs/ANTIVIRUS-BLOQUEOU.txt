┌─────────────────────────────────────────────────────────────────────────┐
│  SOLUÇÃO 1 - ADICIONAR EXCEÇÃO (RECOMENDADO) ⭐                         │
└─────────────────────────────────────────────────────────────────────────┘

Cada antivírus tem um jeito diferente:


🔹 KASPERSKY:
────────────
1. Abra o Kaspersky
2. Configurações (⚙️) → Proteção → Proteção contra Ameaças
3. Role até "Exclusões" → "Gerenciar exclusões"
4. Adicionar → Adicionar arquivo ou pasta
5. Selecione "OrganizadorCapturas.exe"
6. Marque TODAS as opções
7. Salvar


🔹 WINDOWS DEFENDER:
────────────────────
1. Configurações do Windows
2. Privacidade e Segurança → Segurança do Windows
3. Proteção contra vírus e ameaças
4. Gerenciar configurações
5. Exclusões → Adicionar ou remover exclusões
6. Adicionar uma exclusão → Arquivo
7. Selecione "OrganizadorCapturas.exe"


🔹 AVAST / AVG:
───────────────
1. Abra o Avast/AVG
2. Menu → Configurações
3. Geral → Exceções
4. Adicionar Exceção → Procurar
5. Selecione "OrganizadorCapturas.exe"


🔹 NORTON:
──────────
1. Abra o Norton
2. Configurações → Firewall
3. Regras de Programa → Adicionar
4. Selecione "OrganizadorCapturas.exe"
5. Definir como "Permitir"


🔹 MCAFEE:
──────────
1. Abra o McAfee
2. Proteção contra vírus e spyware
3. Arquivos excluídos da verificação
4. Adicionar arquivo
5. Selecione "OrganizadorCapturas.exe"
