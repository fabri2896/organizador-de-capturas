INSTRUÇÕES PARA WINDOWS
================================================================

REQUISITOS
----------
- Windows 10 ou 11, 64 bits
- Nenhuma instalação de Python é necessária (o EXE já traz tudo)

INSTALAR
--------
1. Baixe OrganizadorCapturas-2.0.2-Setup.exe
2. Clique com o botão direito > Executar como administrador (opcional)
3. Escolha o modo:
   - "Instalar para todos os usuários" — pede admin, instala em Program Files
   - "Apenas para mim" — sem admin, instala em %LOCALAPPDATA%\Programs
4. Confirme ou altere a pasta de instalação
5. Marque as opções desejadas (auto-start e atalho na área de trabalho)
6. Instalar > Concluir

O que o instalador faz:
- copia o programa (OrganizadorCapturas.exe + pasta _internal)
- cria atalhos no Menu Iniciar
- grava o auto-start em HKCU\Software\Microsoft\Windows\CurrentVersion\Run
- registra o desinstalador em Configurações > Aplicativos

ATUALIZAR
---------
Baixe o instalador novo e rode por cima. A configuração em
%APPDATA%\OrganizadorCapturas\config.json é preservada — não pede a pasta
de novo. Se o programa estiver aberto, feche antes (o instalador também
consegue fechá-lo automaticamente).

DESINSTALAR
-----------
Configurações > Aplicativos > Organizador de Capturas > Desinstalar
(ou Menu Iniciar > Organizador de Capturas > Desinstalar)

A desinstalação remove o programa, os atalhos e a entrada de auto-start.
O config.json do usuário é mantido de propósito — apague manualmente em
%APPDATA%\OrganizadorCapturas\ se quiser começar do zero.

PROBLEMAS
---------
"O Windows protegeu o seu PC"
    Veja ANTIVIRUS-BLOQUEOU.txt (é só o aviso de programa não assinado)

O programa não abre / nada acontece
    Abra o log: %APPDATA%\OrganizadorCapturas\organizador.log

Não consigo gravar em Program Files
    Instale com a opção "Apenas para mim", que não exige administrador

Pasta monitorada não existe mais
    O programa avisa no log e não organiza nada até você escolher outra
    em Configurar Pasta
