GERENCIAR O INÍCIO AUTOMÁTICO COM O WINDOWS
================================================================

O auto-start fica em:

    HKCU\Software\Microsoft\Windows\CurrentVersion\Run
    Valor: "OrganizadorCapturas"
    Dados: "C:\...\OrganizadorCapturas.exe"

É o mesmo local que o próprio programa usa, então o menu da bandeja mostra
o estado correto (com "∨" quando está ativo).

3 FORMAS DE LIGAR/DESLIGAR
--------------------------

1) Durante a instalação
   Marque ou desmarque "Iniciar o Organizador automaticamente com o Windows".
   Desmarcar também remove uma entrada que já existisse de instalação anterior.

2) Pelo menu da bandeja (mais fácil depois de instalado)
   Botão direito no ícone > "🚀 Iniciar com Windows"
   A marcação "∨" indica que está ligado.

3) Manualmente pelo registro
   Win + R > regedit > navegue até a chave acima
   - Remover: apague o valor "OrganizadorCapturas"
   - Adicionar: crie um valor de texto (REG_SZ) com o caminho do EXE entre
     aspas, por exemplo:
     "C:\Users\você\AppData\Local\Programs\OrganizadorCapturas\OrganizadorCapturas.exe"

VERIFICAR SE ESTÁ ATIVO
-----------------------
Prompt de comando:

    reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v OrganizadorCapturas

Se aparecer o caminho do OrganizadorCapturas.exe, está ligado.
Se aparecer "não foi possível encontrar", está desligado.

DESLIGAR DEFINITIVAMENTE AO DESINSTALAR
---------------------------------------
O desinstalador remove essa entrada automaticamente. Se quiser garantir,
rode o comando de remoção:

    reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v OrganizadorCapturas /f

OBSERVAÇÕES
-----------
- Não precisa de administrador: HKCU é a área do próprio usuário
- Instalando "para todos os usuários", o auto-start continua sendo por
  usuário (cada conta liga o seu)
- Se o valor apontar para um caminho que não existe mais, o Windows ignora
  silenciosamente — basta reinstalar para corrigir
- No Gerenciador de Tarefas > Inicializar, o item aparece como
  "OrganizadorCapturas" e pode ser desativado por lá também
- Versões antigas gravavam "pythonw ...\organizador_tray.py", que nunca
  funcionou. A instalação nova sobrescreve com o caminho correto do EXE.
